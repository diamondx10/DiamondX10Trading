# Decisions log — Quyết định mua / bán

Mọi quyết định mua/bán đều được **thông báo** và ghi vào
`decisions-log.csv` với các cột:

`date, desk, symbol, action, reason, manager`

- `action`: BUY / SELL / HOLD
- `reason`: lý do ngắn gọn, gắn với chiến lược trong `src/`
- File ví dụ: `2026-11-26.example.md` (mô phỏng, không phải lệnh thật)
